# Campus Helpdesk Agent

An AI-Agent Toolchain project incorporating Agent Skills, Plugins, Model Context Protocol (MCP), and Git Worktrees for campus IT/helpdesk workflows.

## Directory Structure

- `report/`: Documentation, audit reports, sources, and prompt logs.
  - `evidence/`: Artifacts, logs, and audit evidence.
  - `sources.md`: Fact-checking and claim verification log.
  - `prompt_log.md`: Interaction and prompt audit log.
- `skills/`: Agent skills specifications and definitions.
- `plugin/`: Agent plugin packaging and configurations.
- `mcp-server/`: Model Context Protocol server implementation.
- `README.md`: Project overview and documentation.
